1Flackey — dark pro-audio direction, all screens
Design reasoning. Dark graphite like pro-audio gear (DJs live in dark UIs: Rekordbox, Ableton), one warm amber accent for "needs you", green strictly for "verified & filed", red for rejections. Every row answers the three questions: a plain-words status line says what is happening now, filed rows show the on-disk path in monospace, and exactly one button per row says what to click. Six-step progress is dots + words, never jargon. Setup runs in a smaller focused window; the app itself is 1200×800.
